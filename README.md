# 🌟 數字小天才

幼兒學數字 1–10 的互動遊戲：認數字、國字、英文、手勢數數、加減與記憶遊戲。

**線上使用**：https://kftseng2oo1.github.io/number/

## 模式
- **🔢 數字／一 國字／🔤 英文**：點數字聽讀音，搭配手指圖
- **🎯 測驗**：找出指定數字、數數看有幾個、這個手勢是幾
- **➕ 加減**：10 以內加減法
- **🧠 記憶**：先記住數字位置，再找出指定數字在哪一格
- 答對有慶祝動畫，達成里程碑會鼓勵

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- `speechSynthesis` 念中文與英文
- 不儲存資料
